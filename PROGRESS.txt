================================================================
  DEPLOYMENT OPTIONS (FREE / LOW COST)
================================================================

OPTION 1 - Docker (Self-hosted, Recommended for Portfolio)
----------------------------------------------------------
- Dockerfile + docker-compose.yml
- Run on any Linux machine, RPi, or cloud VM
- Pros: Reproducible, easy to share, portfolio-friendly
- Cons: Needs a machine running 24/7
- Cost: FREE (hardware/VM cost only)

OPTION 2 - Raspberry Pi (Local, Always-on)
------------------------------------------
- RPi 4 (4GB RAM) recommended
- All features run locally (ChromaDB, Whisper, everything)
- Pros: Private, no cloud costs, real embedded AI device
- Cost: ~$55 hardware (one-time)
- NOTE: Tag v1.0-rpi-ready is your deploy baseline

OPTION 3 - Railway (Free Cloud Hosting)
----------------------------------------
- railway.app - Free tier: $5 credit/month (enough for light use)
- Deploy from GitHub repo directly
- Supports Python/FastAPI natively
- Cons: No persistent disk on free tier (use external DB)
- Cost: FREE (within limits)

OPTION 4 - Render (Free Cloud Hosting)
----------------------------------------
- render.com - Free tier: 750 hours/month web service
- GitHub integration, auto-deploy on push
- Spins down after 15min inactivity (free tier)
- Cost: FREE

OPTION 5 - Hugging Face Spaces (Free, Portfolio Showcase)
----------------------------------------------------------
- huggingface.co/spaces - Free GPU/CPU hosting
- Great for AI demos and portfolio
- Public URL, easy to share
- Supports Gradio or FastAPI
- Cost: FREE

OPTION 6 - fly.io (Free Tier)
-------------------------------
- fly.io - 3 free shared VMs, persistent volumes
- Docker-based deploy
- Better free tier than Render (doesn't sleep)
- Cost: FREE (within limits)

OPTION 7 - Python SDK / Embedded (No Server Needed)
-----------------------------------------------------
- Package core as a Python library: pip install ai-companion
- Run directly on any machine: python -m ai_companion
- Pros: Zero hosting cost, runs anywhere Python runs
- Cons: User must run it locally
- Good for: Open source portfolio / GitHub showcase

================================================================
  RASPBERRY PI COMPATIBILITY NOTES
================================================================
- ChromaDB: YES - runs on RPi 4, uses ~200MB RAM
- Qdrant: YES - has ARM binary, heavier (~400MB RAM)
  Recommendation: ChromaDB for RPi
- sentence-transformers: YES - slow on RPi 3, fine on RPi 4
- openWakeWord: YES - designed for edge devices
- Deepgram API: YES - cloud API, just needs internet
- SerpAPI: YES - cloud API, just needs internet
- Google Calendar API: YES - cloud API
- Spotify API: YES - cloud API
- OpenCV (motion): YES - RPi has official support
- sounddevice/pyaudio: YES - RPi audio works

RECOMMENDED RPi SETUP:
- Raspberry Pi 4 (4GB RAM)
- 32GB+ SD card (Class 10)
- USB microphone or ReSpeaker HAT
- Speaker (3.5mm or USB)
- Optional: PIR sensor for motion detection
